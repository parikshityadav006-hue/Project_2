# CarbonSense – Carbon Emission Calculator and Reduction Advisor

## About the Project

CarbonSense is a college project that aims to help people understand their carbon footprint based on their daily lifestyle activities. The project uses a dataset related to individual carbon footprints and plans to apply machine learning to estimate carbon emissions.

The main idea is not just to calculate emissions, but also to help users understand their results through graphs and explore ways to reduce their carbon footprint.

## Objectives

- Estimate carbon emissions using a machine learning model.
- Understand the dataset and identify useful features.
- Display emission-related information through graphs and charts.
- Help users explore how lifestyle changes may affect their emissions.
- Suggest practical ways to reduce their carbon footprint.

## Dataset

The project uses the **Individual Carbon Footprint Calculation** dataset available on Kaggle.

Dataset link: https://www.kaggle.com/datasets/dumanmesut/individual-carbon-footprint-calculation

The dataset will be inspected and preprocessed before training the model. Only the columns available in the dataset will be considered for model development.

## Project Workflow

1. Load and understand the dataset.
2. Check for missing values and duplicate records.
3. Separate numerical and categorical columns.
4. Preprocess the data and encode categorical features where required.
5. Split the data into training and testing sets.
6. Train a regression model to estimate carbon emissions.
7. Evaluate the model using suitable performance metrics.
8. Develop a web interface to display predictions and visualizations.

## Current Progress
